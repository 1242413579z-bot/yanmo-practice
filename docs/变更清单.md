## 三、音标题作答与判题逻辑修复

| 缺陷 | 修复 |
|---|---|
| 题库写 `tʂ`、面板只提供 `ʈʂ`，用户按面板输入正确读音仅得 10 分 | `GC.IPA.normalizeIPA` 与 `parseSyllable` 把 `tʂ / tʂʰ` 归一为 `ʈʂ / ʈʂʰ`；题库标准答案同步统一 |
| 面板的 `b / d / ɡ / z / A` 等合法 IPA 符号被判为「拼音混用」「大写不规范」而扣 5–10 分 | `normRateOf` 改为只拦截拼音专用字母 `q / ü` 与除 `A` 外的大写字母；`GC.IPA.INITIALS` 补齐面板全部辅音 |
| `ʂər51`（r 表儿化）、`ɚ / ɻ` 写在调值前无法解析 | `parseSyllable` 先归一儿化 r 与「儿化符号在调值前」的写法 |
| 光标放在音节中间点声调，产生 `pʰiɛn3551` | `insertTone` 支持替换光标后的旧调值；空输入框不再插入孤立调值 |
| 音位小题 textarea 聚焦时点面板符号，会插入别的注音框且面板自动收起 | 新增 `state.targets`：注音项与音位小题都是合法插入目标；面板提示切换为「正在输入：音位小题 N」 |

回归断言写入 `tests/test-ipa.mjs` 第 19、20 组（18 项），全部通过。
