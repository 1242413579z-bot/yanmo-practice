## 四、多解（歧义）题说明

- 句法题库中 **56 道题**采用多读法 schema（`readings`，共 112 棵标准树），覆盖南师大、北师大、温大、人大、中国社科院真题与教材歧义短语（「新教工食堂」「热爱人民的军队」「画了一年的画」「三个学校的学生」等）。
- 作答时：做完第一种分析 → 点「＋新增一种分析」→ 做第二种读法；判分按「标准读法数」匹配，缺读法会提示并扣分；解析页逐种读法给出层次分析图 + 一句话释义，并标出你的每份分析对应哪种读法。
- 单解题也可随意新增分析（取最高分，多给不扣分）。

## 五、非真题来源说明

- **模拟题**：按真题风格自编（长难句、多重复句、特殊句式、歧义结构、义素矩阵、标音词语/句子/诗歌、古文句读与翻译），note 中均注明「模拟题」。
- 层次分析在不同教材体系下允许合理异说（「的」是否单列、双宾切分、多层状语结合方向等），题内 note 标「参考答案（按 X 体系）」。
- 2026 南师大 802 翻译两段：按题干所述故事自典籍补录，标 `real:false`（模拟题）。
- 真题原文校订处逐题注明（如《诗集传》「康衡日→匡衡曰」、《左传》「公齮子→公子齮」、《战国策》「嗛→慊」、浙大题「仝人→圣人」等）。
